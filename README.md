# Market — витрина интернет-магазина и сервис платежей

Учебный многомодульный проект интернет-магазина, состоящий из основного приложения-витрины и отдельного REST-сервиса платежей.

Проект реализован на Java и Spring Boot с использованием реактивного стека Spring WebFlux/R2DBC. Для авторизации пользователей используется Spring Security, а взаимодействие витрины с сервисом платежей защищено OAuth2 Client Credentials Flow.

## Возможности

### Витрина интернет-магазина (`storefront`)

- просмотр списка товаров;
- просмотр карточки товара;
- регистрация/хранение пользователей в БД;
- авторизация по логину и паролю;
- выход из аккаунта;
- разграничение доступа для анонимных и авторизованных пользователей;
- персональная корзина пользователя;
- изменение количества товаров в корзине;
- оформление заказа;
- просмотр заказов;
- получение информации о балансе пользователя через сервис платежей;
- выполнение оплаты заказа через сервис платежей;
- OAuth2-аутентификация при обращении к payment service.

### Сервис платежей (`payment`)

- хранение счетов пользователей;
- отдельный баланс для каждого пользователя;
- получение баланса пользователя;
- выполнение платежа;
- проверка достаточности средств;
- сохранение нового баланса в PostgreSQL;
- защита REST API посредством OAuth2 Resource Server и JWT.

## Структура модулей

### `storefront`

Основное веб-приложение.

Отвечает за:

- пользовательский интерфейс;
- аутентификацию пользователей;
- работу с товарами;
- корзины;
- заказы;
- обращение к payment service;
- получение OAuth2 access token для межсервисного взаимодействия.

Основные технологии:

```text
Spring WebFlux
Spring Security
Thymeleaf
Spring Data R2DBC
PostgreSQL
Redis
Liquibase
```

### `payment`

RESTful-сервис платежей.

Отвечает за:

- счета пользователей;
- балансы;
- оплату;
- проверку достаточности средств.

API описывается спецификацией OpenAPI, на основании которой генерируются интерфейсы и DTO.

```text

```

## Авторизация пользователей

Пользователь авторизуется в `storefront` по логину и паролю.

Spring Security определяет текущего пользователя и ограничивает доступ к приватным операциям.

Анонимному пользователю доступны:

- просмотр каталога;
- просмотр карточки товара.

Авторизованному пользователю доступны:

- корзина;
- добавление товаров в корзину;
- оформление заказа;
- просмотр заказов;
- операции, связанные с оплатой.

Корзина и заказы связаны с конкретным пользователем.

## OAuth2 между сервисами

Для взаимодействия `storefront` и `payment` используется OAuth2.
